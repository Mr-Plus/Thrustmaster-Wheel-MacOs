# Extension Chrome : Pont TS-PC Racer -> GeForce NOW & Forza Horizon

Cette extension permet d'utiliser le volant **Thrustmaster TS-PC Racer** sur **GeForce NOW (play.geforcenow.com)** sous macOS Apple Silicon en le transformant en manette Xbox 360 standard reconnue nativement par le flux cloud.

---

## Installation en 30 secondes dans Google Chrome

1. Ouvrez **Google Chrome**.
2. Dans la barre d'adresse, tapez :
   ```text
   chrome://extensions
   ```
3. En haut à droite de la page, activez l'interrupteur **"Mode développeur"** (Developer mode).
4. Cliquez sur le bouton **"Charger l'extension non empaquetée"** (Load unpacked) en haut à gauche.
5. Sélectionnez le sous-dossier `gfn-wheel-extension` de ce projet.
6. L'extension est installée et immédiatement active !

---

## Comment Jouer à Forza Horizon sur GeForce NOW

1. **Branchez votre volant TS-PC Racer** et lancez l'application Mac :
   * Ouvrez `TS-PC Control.app` (le serveur local démarre automatiquement sur le port `8765`).
   * Dans l'onglet **"GeForce NOW (Forza)"**, choisissez votre profil (ex: **Forza Équilibré 540°**).
   * Laissez le ressort de rappel activé à **55%** pour ressentir le volant mécaniquement.
2. **Ouvrez GeForce NOW dans Google Chrome** :
   * Rendez-vous sur [https://play.geforcenow.com](https://play.geforcenow.com).
   * Un badge vert apparaît en haut à droite : **"TS-PC Racer Xbox Bridge"**.
3. **Lancez Forza Horizon 5 (ou 6)** :
   * Le jeu détecte immédiatement une manette Xbox standard.
   * Tournez le volant : la direction tourne avec fluidité.
   * Accélérez et freinez avec vos pédales : les jauges analogiques réagissent en direct !
   * Passez les rapports avec vos palettes gauche et droite.
